# 🧠 AI-Powered Human Attribute Detection
Detect human attributes using artificial intelligence, combining computer vision, Streamlit, and Google Gemini's generative language model.



📷 Project Description
This project leverages cutting-edge AI techniques to identify and analyze human attributes from images — such as estimated age, gender, and emotion. It features a lightweight Streamlit front-end and integrates the powerful Google Gemini GenAI model to generate contextual insights and natural language explanations.

🚀 Features
Interactive image upload through a Streamlit interface

Automated detection of human attributes using AI

Natural language insights powered by Google Gemini

Real-time image annotation and results display

Human-readable explanations of detected attributes

🛠️ Tech Stack
Python

Streamlit

OpenCV

Google Gemini GenAI

Pillow (PIL)

DeepFace (optional)

🌟 Highlights
Combines visual analysis with natural language generation

Focus on interpretability and user-friendly results

Direct integration with a state-of-the-art LLM

Clean, accessible, browser-based interface
